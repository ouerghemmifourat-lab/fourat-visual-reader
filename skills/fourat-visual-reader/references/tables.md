# Tables

## Announce

"A table with {C} columns and {R} rows: {col1}, {col2}, {col3}[, and {C−3} more]. [Values in {unit}.]"
FR : « Un tableau de {C} colonnes et {R} lignes : {col1}, {col2}, {col3}[ et {C−3} autres]. [Valeurs en {unit}.] »

- Count data rows, not the header row. If a total row exists, say "plus a total row".
- Name the row-header column first ("one row per city").
- Multi-level headers: split into several simple tables and say how many ("I'll read it as two tables: 2023 and 2024").

## Message

Pick the main numeric column (the first one, or the one the title names) and state the dominant reading: the largest, the
smallest, or the trend if rows are ordered in time. One sentence: "Tokyo has by far the largest population; Reykjavik the
smallest."

## Key figures

Two or three sentences, one number each, each with its row label, column name and unit:
"Tokyo, population: about 37 million." "Reykjavik: 130 thousand." "The total across the 12 cities is 98 million."

## Size rules

| Size | Rule |
|---|---|
| Small: ≤ 4 columns and ≤ 6 rows | announce, message, then read all rows without waiting |
| Medium: ≤ 8 columns and ≤ 30 rows | announce, message, key figures, offer |
| Large: more | announce, message, key figures, then offer a **smaller table** first: top N, one column, a filter, a sort; never a linear read without an explicit request |

## Reading rows

"Row {i} of {R}, {row label}: {col} {value}; {col} {value}; {col} {value}."
- Groups of 3 to 4 rows, position announced once per group ("Rows 4 to 6 of 12").
- With exactly two value columns you may drop the column names after the first group ("Lyon: 0.5 million, 48 square
  kilometres") if the order is obvious; restore them whenever the listener asks "which is which".
- Keep the unit on the first value of each group and whenever it changes.

## Reading a column

"Column {col}, top to bottom: {row} {value}; {row} {value}; {row} {value}." Groups of 3 to 4. Give the maximum and
minimum first if the listener asked for the column in order to compare.

## Comparing rows

"Paris versus Lyon. Population: 2.1 million against 0.5 million, four times more. Area: 105 against 48 square
kilometres." Column by column, both values in one sentence, the relation in plain words.

## Cells that are not numbers

- Empty: "no value". Dash: say what it means in this table ("not applicable", "zero", "unknown"); if unknown, "a dash".
- Footnote marker: "footnote 1" once, then read the note when the row is finished or when asked.
- Yes/no, ticks: "yes" / "no"; coloured cells: say the meaning given by the legend, never the colour alone.
- Long text cells: read them; offer to skip them if the table has many.

## Positions and wayfinding

- Position at the start of each group, not each row.
- "Where am I?": figure, current row and label, current column, unit.
- When resuming after an interruption, repeat the last row label before continuing.

## Statistics on request

Maximum, minimum, total, average, count of rows matching a condition: compute from the data, say the operation ("the
total of the Population column"), round to three significant figures, offer the exact value.
